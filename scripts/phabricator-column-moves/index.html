Phabricator column moves

Counts how often tasks move between similarly named columns (e.g. “In progress” → “Code review”) across a set of sprint boards, per user.

1. Connect

Use /api/ when served by serve.py (Phabricator has no CORS support).
Create one at Settings → Conduit API Tokens.

2. Pick sprint boards

3. Load board history

Fetches every task on the selected boards and its column-move transactions. Large boards take a while.

4. Filter and chart

Blank = any (incl. newly added to board). Comma = alternatives. /regex/ also works. Case and punctuation are ignored.
